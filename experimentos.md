# Experimentos

Uma linha por ideia aplicada. O "antes" de cada mudança é a linha de base ou a mudança anterior, e a coluna "Antes usado" diz qual. Todo número vem dos arquivos de `resultados/` (medianas das três execuções). Os parâmetros de carga são os mesmos em todas as medições: 20 usuários virtuais, 60 s, semente 42.
